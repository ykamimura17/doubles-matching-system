# 自動マッチングの選出・ペア履歴評価

## 出場選手の選出

待機中の選手から試合回数の少ない選手を優先して4名選出する。

同じ試合回数の候補が選出枠より多い場合は、**獲得ポイントの上位2名・下位2名**を優先して選ぶ。試合回数の少ない選手を飛ばしてポイント上位・下位を取ることはしない。

同じ試合回数の候補に対して残り枠が4名未満の場合、4名枠の考え方を縮小して以下のように選ぶ。

- 残り1枠：ポイント上位1名
- 残り2枠：ポイント上位1名・下位1名
- 残り3枠：ポイント上位2名・下位1名

ポイントが同数の場合は待機選手リスト上の順番を維持する。

## チーム分け

選出4名による3通りのペア分けを比較する。

選手評価値は `level × 50 + point × 10` とする。

組み合わせスコアは「両チームの評価値合計の差の絶対値 + 1000 × （両チームの過去ペア回数の合計）」とし、最小スコアの組み合わせを採用する。

保存されている `pairHistory` 全件を評価する。直近10組に絞らず、同じペアを組んだ回数に応じて評価値へ加算する。選手IDの順序は問わない。

ペアの再結成を禁止するものではなく、対戦相手ペアの重複判定も追加しない。

現状は大会IDで履歴を分離していないため、大会開始時にペア履歴をリセットして運用することを前提とする。
