# 選手管理

FigmaのMobileプレイヤー一覧（6:81）、Desktop一覧（6:161）、選手登録（6:240）を基に、既存画面の選手セクションを更新。

- PCはテーブル、スマホは頭文字アイコン付きカード。人数集計、状態フィルター、ポイント・勝敗分・試合数を表示。
- 管理者のみ選手登録、編集、休憩/復帰、コート数1〜12の変更が可能。
- 登録項目は名前（必須50文字以内）、レベル（初級/中級/上級）、状態（待機/休憩）、コメント（任意300文字以内）。戦績は0から開始。
- `POST /api/players` はIDトークンとadmin claimを検証後、`system/current` をトランザクションで更新。同時操作でもIDを一意に割り当て、戦績・履歴は保持。
- 試合中、または使用中コートのチームに含まれる選手は編集・状態変更を拒否。試合中コートをなくすコート数削減も拒否。
- 選手の削除は対象外。Firestoreルール・IAM・環境変数の追加変更は不要。

全体のページ内ナビゲーション、コート画面、ランキング・履歴の既存レイアウトは今回変更しない。Figmaの独立画面・サイドバーへの移行は後続対応。

単体テストは入力検証、戦績保持、ID採番、試合中の整合性を確認。業務ドメインごとのPlaywright E2Eは正常系のみをPC/スマホで実行。E2Eは固定データで、実Firebaseに書き込まない。実環境の登録・更新は公開後に別途確認する。
