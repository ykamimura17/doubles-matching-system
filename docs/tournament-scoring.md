# 社内大会の配点・順位

- 新しく結果を登録する試合は勝ち3点、引分け1点、負け−1点。4ゲーム固定は維持。
- 順位は合計ポイント、勝率（勝ち数÷試合数。未出場は0）、勝ち数、総取得ゲーム数、負け数（少ない順）。全条件が同じ場合は1位・1位・3位の同率順位。
- ホーム、ランキング、MVP/SVPは共通判定。1位全員がMVP、2位全員がSVP。同率1位により2位がない場合はSVPなし。
- 取得ゲームは終了した試合履歴から集計し、修正・削除を反映。新規履歴は選手IDも保存する。旧履歴は一意な選手名で照合するため、名前変更や同名選手のある旧履歴は正確な照合ができない場合がある。
- 既存DBの再集計・移行・リセットは行わない。旧履歴（lossPointなし）は敗北0点、新規履歴はlossPoint=-1として修正・削除時に元の配点を維持する。
- マッチングは変更しない。同一ペア同士の再戦回避を強化する未マージPR #20も取り込まない。
- 保存済みのルール説明は上書きしない。未設定時の表示に今回の大会ルールを使用する。登録済みの説明は管理者がホームで更新できる。
- サーブの本数は説明として掲載し、現場で運用する。
