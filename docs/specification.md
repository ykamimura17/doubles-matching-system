# 🎾 ダブルスマッチングシステム 仕様書 Ver1.0

## 概要

テニス部のダブルス練習会向けの試合運営アプリ。

管理者が参加者を登録し、自動マッチングや手動マッチングを実施する。

参加者はリアルタイムで以下の情報を確認できる。

- 現在の試合状況
- コート状況
- ランキング
- MVP / SVP
- 試合履歴

# プレイヤー管理

## レベル

- 上級 = 3（評価値300）
- 中級 = 2（評価値200）
- 初級 = 1（評価値100）

## ステータス

- 待機中（青）
- 試合中（赤）
- 休憩中（グレー）

休憩中・試合中はマッチング対象外。

---

# コート設定

- 1〜6面
- 選出人数 = コート数 × 4人

例：3面 → 12人選出

---

# 試合形式

- 4ゲーム固定
- 勝ち +3pt
- 引き分け +1pt
- 負け -1pt

入力例：

```text
4-0
3-1
2-2
```

---

# 自動マッチング

優先順位：

1. 試合数が少ない人
2. 待機中のみ対象
3. レベル + ポイント評価
4. 直近10試合のペア回避
5. チーム戦力差最小

評価値：

```text
(level × 100) + (point × 10)
```

---

# 手動マッチング

- ボタン押下時のみ入力エリア表示
- チームA、チームBを自由選択
- 空きコートへ割り当て

---

# コート状況

表示例：

```text
コート1 🔴試合中
安村 & 田中
VS
佐藤 & 山本
```

```text
コート2 🟢空き
```

---

# ランキング

- 初期状態は非表示
- ボタン押下で表示
- ポイント降順

---

# MVP / SVP

表示内容：

- 名前
- ポイント
- 勝数
- 引分数
- 敗北数
- 勝率
- 試合数

MVP：ポイント1位
SVP：ポイント2位

---

# 試合履歴

- 新しい順
- 1ページ10件表示
- 前へ / 次へでページ移動

管理者のみ：

- 結果修正
- 履歴削除
