# ホームの大会ルール

- ホームの大会ルール欄は全参加者が閲覧できる。
- 管理者のみ「ルールを編集」から変更・保存できる。キャンセルは保存しない。
- 説明文は改行可能なプレーンテキスト、最大5000文字。空欄保存で未登録表示に戻る。
- `system/current.rulesDescription` に保存し、既存のリアルタイム購読で表示を更新する。未追加の既存ドキュメントにも対応する。
- `POST /api/rules` は既存の `requireAdmin` によってIDトークンとadmin claimを検証し、rulesDescriptionだけを更新する。Firestoreルールの変更は不要。
- 実際のスコア入力条件やポイント計算は変更しない。
